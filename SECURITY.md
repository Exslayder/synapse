# Security Policy

## Что делает приложение

Synapse запускает локальный HTTP/HTTPS-прокси на `127.0.0.1` и открывает браузер с отдельным профилем. Прокси разрешает имена только через настроенный DoH-сервер (с необязательным TCP DNS/53 fallback) и блокирует непубличные IP-адреса.

## Модель угроз

- Прокси не имеет аутентификации, но слушает только loopback. Пока приложение запущено, любой локальный процесс может использовать его как HTTP-прокси. Не запускайте приложение на общем компьютере с недоверенными пользователями.
- TLS-трафик к сайтам не расшифровывается: прокси работает как `CONNECT`-туннель.
- DoH-сервер и bootstrap-IP задаются пользователем. Недоверенный DoH-сервер может возвращать произвольные публичные IP; TLS-сертификат сайта при этом всё равно проверяется браузером.
- `profiles/` содержит cookies и сессии. Защищайте папку и не публикуйте её.
- Сборки не подписаны. Проверяйте SHA-256 и источник загрузки.

## Сообщения об уязвимостях

Не открывайте публичный issue для уязвимости. Используйте приватный отчёт GitHub Security Advisories в репозитории проекта и приложите версию, шаги воспроизведения и журнал без персональных данных.
