## Редактирование сайтов на главной странице

Статус: обсуждается, не реализовано.

Идея: перенести редактирование списка сайтов из «Настройки → Сайты» на главный экран.
Кнопку «Изменить список» переименовать в «Изменить».

В режиме редактирования на главной:

- имя и URL каждого сайта редактируются прямо в карточке;
- есть удаление сайта и добавление нового;
- drag-and-drop для порядка сохраняется;
- кнопки «Сохранить» и «Отмена»;
- кнопки «Открыть», закрепление и direct на время редактирования скрываются,
  чтобы не нажать их случайно.

Важные детали:

- не менять `id` существующего сайта при редактировании имени/URL, иначе
  потеряется его профиль браузера и сессия;
- для нового сайта `id` генерируется из домена/названия, как в настройках;
- нельзя удалить последний сайт;
- удаление — с подтверждением;
- валидация имени и `http(s)://` URL;
- главная страница опрашивает `get_state` каждые 1.5 секунды и перерисовывает
  карточки через `innerHTML`; в режиме редактирования нужно приостанавливать
  перерисовку или сохранять черновик, иначе ввод и фокус будут теряться;
- после сохранения — обновить состояние, после отмены — восстановить прежнее;
- в настройках вкладку «Сайты» после переноса убрать, чтобы не было двух
  редакторов одного списка;
- при удалении сайта старая папка `profiles/<id>` остаётся; при необходимости
  добавить очистку или ручное управление.
