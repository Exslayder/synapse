Synapse — портативная версия
============================

В архиве:
  Synapse.exe            — приложение
  xray.exe               — VPN-компонент (нужен для режима VPN)
  README-PORTABLE.txt    — этот файл
  xray-LICENSE.txt       — лицензия Xray-core (MPL-2.0)

Установка
---------
1. Распакуйте архив в отдельную папку.
2. Убедитесь, что Synapse.exe и xray.exe лежат рядом.
3. Запустите Synapse.exe.
4. Откройте «Настройки → Подключение» и выберите режим:
   • DoH — укажите адрес DNS-over-HTTPS;
   • VPN — вставьте ссылку vless:// и нажмите «Сохранить».

Обновление
----------
Замените Synapse.exe и xray.exe на новые из архива.
Не удаляйте:
  config.json   — настройки
  profiles/     — профили браузеров и сессии
  logs/         — журналы
  tunnel.dat    — сохранённая VPN-ссылка (зашифрована Windows DPAPI)

Если обновляетесь с версии без xray.exe — просто положите его рядом с Synapse.exe.

VPN
---
Synapse запускает локальный Xray и направляет обычные сайты через ваш
VLESS/Reality-сервер. Сайты с флагом «без DoH» (direct) идут напрямую.
DoH и VPN взаимоисключающие: одновременно используется только один режим.

Ссылка VPN хранится в tunnel.dat в зашифрованном виде и привязана к текущей
учётной записи Windows. При переносе на другого пользователя или компьютер
ссылку нужно ввести заново. Не публикуйте tunnel.dat и папку profiles.

Если антивирус жалуется на неподписанный xray.exe, сверьте SHA-256 с релизом
на GitHub и добавьте исключение только если уверены в источнике.
