# Changelog

## Не выпущено

- В релиз снова публикуется отдельный `synapse.exe`: он нужен портативным сборкам 2.0.5 и старше, которые иначе не находят файл для самообновления. Портативные версии 2.0.6 и новее по-прежнему получают `Synapse_portable.zip`.

## 2.0.6 (2026-11-06)

- Портативная сборка теперь содержит подробную инструкцию по обновлению: что заменять, что нельзя удалять и зачем нужен `xray.exe`.
- Глобус на карточке сайта учитывает режим: при включённом VPN он переключает сайт между туннелем и прямым подключением, активная кнопка помечается «без VPN».
- Убран постоянный текст «у каждого свой профиль»: пояснение о профилях показывается при наведении на заголовок «Сайты».
- Плейсхолдеры «ключ сохранён» и «определяется автоматически» получили более читаемый шрифт и цвет; статус туннеля оформлен компактным индикатором с точкой и мягкой пульсацией.
- Настройки обновлений: тип установки определяется автоматически (портативная, NSIS или MSI), скачивается соответствующий файл; в баннере видно, какая версия установлена.
- Настройки приведены в порядок: таймаут DoH перенесён в раздел «DNS-over-HTTPS», «Прокси» переименован в «Локальный прокси» с пояснением, что через него работают оба режима.
- Удалено неиспользуемое поле `last_update_check` и дублирующая функция в интерфейсе настроек; проверка IP больше не ломает индикатор состояния VPN.

## 2.0.5 (2026-11-04)

- Добавлен VLESS/Reality VPN через Xray. Вы вставляете ссылку `vless://` в настройках, Synapse запускает Xray с локальным SOCKS5 на `127.0.0.1`, и обычные сайты идут через ваш VPN-сервер. Сайты с флагом `direct` по-прежнему идут напрямую.
- DoH и VPN взаимоисключающие: в настройках выбирается один режим — DoH или VPN. При включённом VPN DoH для обычных сайтов не используется; если Xray не запустился, приложение не откатывается на DoH.
- Переключатель режима показывает только настройки выбранного варианта; на главной странице плитка называется «Подключение» и показывает, что используется сейчас.
- Ссылка хранится зашифрованной через Windows DPAPI в `tunnel.dat`; в `config.json` и журнал она не попадает. Xray-конфиг с секретами создаётся во временной папке пользователя и удаляется после старта.
- `xray.exe` подключается как sidecar; добавлены проверки ссылки, SOCKS5-подключение по имени хоста (remote DNS), запуск/остановка туннеля и кнопка проверки внешнего IP.
- Портативная версия теперь поставляется как `Synapse_portable.zip` с `Synapse.exe`, `xray.exe` и инструкцией по обновлению.
- Сборки тянут Xray по закреплённым версии и SHA-256 через `.github/scripts/fetch-xray.ps1`.

## 2.0.4 (2026-11-02)

- Кнопка «Обновить» скачивает подходящий файл (портативный exe, установщик или MSI) в «Загрузки», проверяет SHA-256 и открывает папку с файлом; установка и замена выполняются вручную.
- Скачанный файл проверяется по SHA-256 из данных GitHub, при несовпадении обновление отменяется.
- Если скачанный файл удалён антивирусом, приложение сообщает об этом вместо ложного «Скачано».
- Если автообновление недоступно (нет подходящего файла или контрольной суммы), кнопка открывает страницу релиза.
- В баннере обновления убрано описание изменений: осталась только установленная версия, подробности открываются по ссылке «Что нового».
- Крестик скрывает баннер только до перезапуска: при следующем запуске предложение обновления появляется снова, если новая версия всё ещё доступна.

## 2.0.3 (2026-11-01)

- Подпись под логотипом больше не меняет размер шрифта при изменении окна: фиксированные 12,5 px и перенос на две строки на узком окне.
- Иконки для iOS, Android, macOS и Windows Store удалены; остались только иконки, нужные Windows-сборке.
- Из карточек сайтов убрана подпись «отдельный профиль» — подсказка перенесена к заголовку «Сайты».
- Убраны статусы «Готов» и «Открыт»; отключённый сайт по-прежнему помечается «выключен».

## 2.0.2 (2026-11-01)

- Проверка обновлений при запуске: приложение сравнивает свою версию с последним релизом на GitHub.
- Если вышла новая версия, на главном экране появляется баннер «Доступно обновление» с кнопкой «Обновить» и ссылкой «Что нового».
- Кнопка «Обновить» открывает загрузку установщика новой версии в браузере по умолчанию, ссылка ведёт на страницу релиза.
- Баннер не показывается, если версия актуальна, проверка отключена в настройках или GitHub недоступен.
- Переключатель «Проверять обновления» в настройках полностью отключает запрос к GitHub: при выключенном положении ни проверки, ни сетевого обращения нет.
- Скрытый баннер больше не появляется до следующей версии.
- Определение браузера: добавлены Brave, Vivaldi и Opera; системный браузер по умолчанию распознаётся по реестру.
- Определение браузера выполняется при запуске, сохранении настроек и открытии сайта — без фоновых таймеров.
- Положение и размер окон сайтов запоминаются в конфиге и восстанавливаются при следующем открытии.
- Примечания к релизам на GitHub теперь формируются из этого файла: раздел с номером версии становится описанием релиза.

## 2.0.1 (2026-10-31)

- Старт приложения ускорен: браузер по умолчанию определяется через реестр без запуска `reg.exe`, проверка «осиротевших» окон вынесена в фон.
- Компактное окно по умолчанию (660×980) вместо широкого; собственный размер по-прежнему сохраняется в конфиг.
- В журнал добавлен замер времени инициализации.

## 2.0.0 — «Импульс» (2026-10-31)

Полностью новый клиент: Python и tkinter заменены на Tauri 2 (Rust + WebView2).

- Четыре сервиса в отдельных окнах браузера, у каждого свой профиль и своя сессия.
- Локальный HTTP/HTTPS-прокси с DNS-over-HTTPS: HTTP/2, bootstrap-IP, кэш ответов, откат на системный DNS.
- Собственный DoH-сервер на пользователя: в конфиге по умолчанию пусто, адрес задаётся в настройках.
- Обход DoH для отдельных сайтов, если провайдер фильтрует домен.
- Проверка доступности сайтов с индикатором и записью причины в журнал.
- Закрепление окон поверх всех с приоритетом по порядку списка.
- Перетаскивание сайтов и сохранение порядка.
- Настройки с вкладками «Общие» и «Сайты»: названия, адреса, добавление и удаление сайтов.
- Журнал с фильтрами, поиском, копированием и очисткой.
- Портативный режим: конфиг, профили и журналы рядом с exe.
- Сборка релизов и еженедельное обновление зависимостей через GitHub Actions.
