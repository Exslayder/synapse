# Changelog

## 1.0.2 — 2026-10-31

- **DoH больше не навязан.** Встроенный сервер и bootstrap-IP убраны, кнопка «Сбросить на Dagami» удалена. Поле DoH изначально пустое: Synapse использует только адрес, который ввёл пользователь.
- **Работа без DoH.** Если адрес не задан, прокси разрешает имена через системный DNS, а главное окно и журнал явно показывают «DoH не настроен». «Проверить DNS» при пустом поле сообщает, что сначала нужно указать сервер.
- **Проект переименован в `synapse`.** Пути, пакет, сборка и документация больше не используют старое имя `gemini-doh`.

## 1.0.1 — 2026-10-31

- **Чужой браузер больше не закрывается.** При выходе Synapse закрывает только те процессы, которые запустила сама, и сверяет PID с исполняемым файлом браузера. Раньше окна искались по заголовку: рабочий Firefox или Chrome с открытым ChatGPT/Gemini мог закрыться вместе с программой.
- **Полная изоляция профилей.** Firefox запускается с `-new-instance -no-remote` и своим профилем, Chrome — с отдельным `--user-data-dir` и флагами, отключающими общие службы обновлений и фоновые задачи. Основной браузер, его закладки, входы и настройки не затрагиваются.
- **Ctrl+Z и Ctrl+Y.** В полях настроек работает отмена и повтор ввода, в том числе при русской раскладке; повтор также доступен по Ctrl+Shift+Z. В контекстном меню появились «Отменить» и «Повторить».

## 1.0.0 — 2026-10-30

Первый публичный релиз **Synapse** — Windows-центра для AI-чатов с локальным DoH-прокси.

- **Новое имя и логотип.** Проект переименован из рабочего «Gemini DoH» в **Synapse** (синапс — связь нейронов и сетевой узел). Обновлены заголовок окна, иконка, `.exe`, папка данных, переменные окружения и документация.
- **Gemini, ChatGPT, Claude, Grok** — каждое приложение открывается в отдельном окне браузера со своим постоянным профилем и сохранённым входом.
- **Chrome и Firefox / Nightly** — Chrome открывает настоящее окно приложения (`--app`), Firefox работает через отдельный профиль с прокси в `user.js`. Движок выбирается в настройках.
- **Живой статус сайтов.** Зелёная метка «открыто» привязана к реальному видимому окну браузера в дереве процессов: после закрытия окна она исчезает, а не остаётся висеть.
- **Буфер обмена без сюрпризов.** `Ctrl+A/C/V/X` работают в полях настроек и диалогах независимо от раскладки (включая русскую), плюс контекстное меню по правой кнопке. Выделение текста, полей и строк списка получило контрастный цвет и теперь хорошо заметно.
- **Свой DoH-сервер** — адрес, bootstrap-IP, таймаут и резервный DNS/53 настраиваются в окне «Настройки», проверка DNS выполняется до сохранения.
- **Закрепление окон** — главное окно и окна сайтов удерживаются поверх остальных через Win32 `HWND_TOPMOST` и дерево процессов конкретного окна.
- **Гибкое окно** — изменение размера, пресеты «Компактный / Обычный / Широкий», запоминание геометрии.
- **Обновления** — проверка GitHub Releases, индикатор в главном окне, вкладка «Обновления», скачивание `.exe`, флаг `--check-updates`, авто-проверка раз в сутки.
- **Чистый интерфейс** — индиго-палитра, нативные кнопки, переключатели и чекбоксы с чётким ClearType-текстом, тёмный заголовок окна Windows 10/11. Убрана лишняя кнопка копирования DoH-адреса: адрес и так можно выделить и скопировать из поля.
- **Конфиг рядом с программой** — `config.json` в папке скрипта или `.exe`, атомарная запись и резервная копия повреждённого файла.
- **Без сторонних runtime-зависимостей** — только стандартная библиотека Python и tkinter.
- **Готовый `.exe`** — onefile-сборка PyInstaller, GitHub Actions с тестами, релизами по тегам и еженедельной сборкой.
- **Тесты** — 101 unit-тест без сети: DNS-пакеты, DoH, конфиг, прокси, обновления, браузеры, склонения и файлы проекта.
