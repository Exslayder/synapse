# Changelog

## 2.0.2 (2026-11-01)

- Проверка обновлений при запуске: приложение сравнивает свою версию с последним релизом на GitHub.
- Если вышла новая версия, на главном экране появляется баннер «Доступно обновление» с кнопкой «Обновить» и ссылкой «Что нового».
- Кнопка «Обновить» открывает загрузку установщика новой версии в браузере по умолчанию, ссылка ведёт на страницу релиза.
- Баннер не показывается, если версия актуальна, проверка отключена в настройках или GitHub недоступен.
- Переключатель «Проверять обновления» в настройках полностью отключает запрос к GitHub: при выключенном положении ни проверки, ни сетевого обращения нет.
- Скрытый баннер больше не появляется до следующей версии.
- Определение браузера: добавлены Brave, Vivaldi и Opera; системный браузер по умолчанию распознаётся по реестру.
- Определение браузера выполняется при запуске, сохранении настроек и открытии сайта — без фоновых таймеров.
- Положение и размер окон сайтов запоминаются в конфиге и восстанавливаются при следующем открытии.
- Примечания к релизам на GitHub теперь формируются из этого файла: раздел с номером версии становится описанием релиза.

## 2.0.1 (2026-10-31)

- Старт приложения ускорен: браузер по умолчанию определяется через реестр без запуска `reg.exe`, проверка «осиротевших» окон вынесена в фон.
- Компактное окно по умолчанию (660×980) вместо широкого; собственный размер по-прежнему сохраняется в конфиг.
- В журнал добавлен замер времени инициализации.

## 2.0.0 — «Импульс» (2026-10-31)

Полностью новый клиент: Python и tkinter заменены на Tauri 2 (Rust + WebView2).

- Четыре сервиса в отдельных окнах браузера, у каждого свой профиль и своя сессия.
- Локальный HTTP/HTTPS-прокси с DNS-over-HTTPS: HTTP/2, bootstrap-IP, кэш ответов, откат на системный DNS.
- Собственный DoH-сервер на пользователя: в конфиге по умолчанию пусто, адрес задаётся в настройках.
- Обход DoH для отдельных сайтов, если провайдер фильтрует домен.
- Проверка доступности сайтов с индикатором и записью причины в журнал.
- Закрепление окон поверх всех с приоритетом по порядку списка.
- Перетаскивание сайтов и сохранение порядка.
- Настройки с вкладками «Общие» и «Сайты»: названия, адреса, добавление и удаление сайтов.
- Журнал с фильтрами, поиском, копированием и очисткой.
- Портативный режим: конфиг, профили и журналы рядом с exe.
- Сборка релизов и еженедельное обновление зависимостей через GitHub Actions.
