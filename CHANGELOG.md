# Changelog

## 2.0.0 — 2026-10-28

- Полностью переписан проект: пакет `gemini_doh`, запуск из исходников и onefile EXE.
- Несколько сайтов: Gemini, ChatGPT, Claude, Grok; отдельный профиль браузера для каждого.
- Список ссылок в главном окне, открытие одного или всех сайтов, сортировка и скрытие.
- Настройка DoH-сервера, bootstrap-IP, таймаута и резервного DNS/53; проверка DNS до сохранения.
- Закрепление главного окна и окон сайтов поверх остальных.
- Изменяемый размер окна, пресеты и сохранение геометрии.
- `config.json` рядом с программой, атомарная запись и резервная копия повреждённого файла.
- Исправлены: chunked-ответы DoH, проверка ID/QR DNS, SSRF для буквальных IP, кодировка имён.
- GitHub Actions: тесты, сборка EXE, релизы по тегам и еженедельная сборка.
- Список сайтов подстраивается под количество карточек, полоса прокрутки появляется только при переполнении.
