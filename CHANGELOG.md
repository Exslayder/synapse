# Changelog

## 2.1.0 — 2026-10-28

- Два движка браузера: **Google Chrome** (окно приложения `--app`, основной) и **Firefox / Nightly** (отдельный профиль, прокси в `user.js`, отключены приветствие и ToU-модал). Выбор — «Авто / Chrome / Firefox / Другой файл».
- Новый интерфейс: индиго-палитра, скруглённые карточки, переключатели, сегментированные разделы настроек, тёмный заголовок окна Windows 10/11.
- Проверка обновлений через GitHub Releases: индикатор в главном окне, вкладка «Обновления», скачивание `.exe`, флаг `--check-updates`, авто-проверка раз в сутки.
- Закрепление окон и закрытие теперь работают по PID и дереву процессов, а не только по заголовку; повторное «Открыть» фокусирует уже открытое окно.
- `config.json` версии 3: добавлены `auto_check_updates` и `last_update_check`; значения браузера `auto / chrome / firefox / custom`.
- Обновлены README, CHANGELOG, иконка и скриншот; добавлен `docs/PUBLISHING.md` с полной инструкцией выкладки на GitHub.
- Новые тесты: `updater` (разбор релизов, сравнение версий, скачивание) и `browser` (`user.js`, определение Firefox, дерево процессов). Всего 95 тестов.

## 2.0.0 — 2026-10-28

- Полностью переписан проект: пакет `gemini_doh`, запуск из исходников и onefile EXE.
- Несколько сайтов: Gemini, ChatGPT, Claude, Grok; отдельный профиль браузера для каждого.
- Список ссылок в главном окне, открытие одного или всех сайтов, сортировка и скрытие.
- Настройка DoH-сервера, bootstrap-IP, таймаута и резервного DNS/53; проверка DNS до сохранения.
- Закрепление главного окна и окон сайтов поверх остальных.
- Изменяемый размер окна, пресеты и сохранение геометрии.
- `config.json` рядом с программой, атомарная запись и резервная копия повреждённого файла.
- Исправлены: chunked-ответы DoH, проверка ID/QR DNS, SSRF для буквальных IP, кодировка имён.
- GitHub Actions: тесты, сборка EXE, релизы по тегам и еженедельная сборка.
- Список сайтов подстраивается под количество карточек, полоса прокрутки появляется только при переполнении.
